## Autonomous Agent Commands

You can interact with `faserf-hermes-agent[bot]` in issues and pull requests using standard commands:
* `@faserf-hermes-agent review` — Request an on-demand, line-by-line automated code review with suggestions.
* `@faserf-hermes-agent resolve` — Request autonomous investigation and bugfix PR generation via OpenHands.
* `@faserf-hermes-agent help` — Display supported commands and capabilities.
